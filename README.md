# Resume Editor 📝

A modern Resume Editor built with React, allowing users to create, preview, and edit professional resumes in real-time with a true A4 single-page layout. Perfect for building resumes for job applications, and designed for smooth PDF export.

---

## 🚀 Features

- **Live Resume Preview**: See changes instantly as you fill the form.
- **A4 Layout**: Real A4 page size preview for accurate printing or PDF export.
- **Single-page Scaling**: Entire resume visible without scrolling.
- **Dynamic Sections**: Add Education, Experience, Skills, and Projects.
- **Clean and Minimal UI**: Professional look for resumes.
- **Ready for PDF Export**: Print or save as PDF easily.
- **Responsive Design**: Works on different screen sizes.

---

## 🛠 Tech Stack

- **Frontend**: React (Vite)
- **Styling**: CSS
- **JavaScript**: ES6+
- **Version Control**: Git & GitHub
- Optional: Future PDF export using `jspdf` or `html2pdf`
